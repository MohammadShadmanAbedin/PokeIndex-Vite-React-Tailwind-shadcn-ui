# PokeIndex

Pokedex app built with Vite + React + Tailwind CSS + shadcn/ui.
Data comes from https://pokeapi.co

## Hooks used
- useState: pokemon list, search text, loading flag, selected pokemon
- useEffect: fetch data from the API when a page loads
- useNavigate: card click -> detail page, Back / Prev / Next buttons

## Run
npm install
npm run dev
